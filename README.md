# 👻 Ghost Chat

A Python Tkinter based AI Voice Assistant with:

✅ Chat UI  
✅ Voice Input (SpeechRecognition)  
✅ Text To Speech  
✅ Games (Snake + Tic Tac Toe)  
✅ Tasks Manager  
✅ Themes & Personalities  
✅ Local AI support (Ollama)

---

## 🚀 Features

- Modern GUI using Tkinter  
- Voice commands  
- Local AI using Ollama (Llama 3.2)  
- Mini games  
- To-do list  
- Screenshot tool  
- Themes & settings  

---

## 🛠 Requirements

Python 3.9+

```bash
pip install pillow pyttsx3 SpeechRecognition pyaudio ollama
